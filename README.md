# Démo créateurs — GitHub Pages

## Contenu
- `index.html`
- `styles.css`
- `demo-partenariats-createurs.mp4`
- `poster.jpg`

## Mise en ligne
1. Créez un dépôt GitHub, par exemple `demo-createurs`.
2. Ajoutez les 4 fichiers à la racine du dépôt.
3. Ouvrez **Settings > Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**.
5. Sélectionnez `main` et `/ (root)`.
6. Cliquez sur **Save**.
7. L’URL sera du type `https://VOTRE-COMPTE.github.io/demo-createurs/`.

Le nom de marque n’est volontairement pas affiché puisque le nom final du projet n’est pas encore choisi.
